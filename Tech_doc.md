Тема выпускной квалификационно работы
«Проектирование и разработка системы поддержки закупочной деятельности с использованием подходов многокритериального анализа»

 Блок 1: Приоритетные задачи
Система размещается on-premise, работает через веб-интерфейс. Данные хранятся локально. Поддержка загрузки файлов, обработки, генерации XLS, хранения и скачивания. Разграничение доступа по ролям. Для внешних поисков система имеет доступ к интернету и открытым источникам.

 1. Автоматическое заполнение XLS-формы для ЕИС на основе договора и акта
Описание функционала:
Загрузка приложения к договору и акта. Извлечение услуг, количества, стоимости из акта. Автозаполнение шаблона XLS для ЕИС. Хранение и скачивание готовой формы. Версионность, уведомления.
Перечень входных данных:
- Приложение к договору: файл (PDF, XLS/XLSX) с табличными данными о услугах (наименование, количество, стоимость, единицы измерения).
- Акт оказания услуг: файл (PDF, XLS/XLSX) с деталями фактически оказанных услуг (наименование, объем, стоимость, дата акта).
- Шаблон XLS-формы для ЕИС: предзагруженный файл XLS/XLSX с фиксированной структурой (поля: ИНН контрагента, номер договора, суммы, коды услуг).
- Дополнительные метаданные: номер договора (строка), дата договора (дата), ИНН/КПП организации и контрагента (строки), пользовательские комментарии (текст).
 2. Обработка реестров платежей и договоров с расчетом процентов и формированием отчета
Описание функционала:
Загрузка реестров платежей и договоров. Объединение данных (в третий файл). Расчет процентов СМСП-договоров и закупок для СМСП с фильтрами (исключение нерелевантных). Распределение по критериям в XLS. Генерация отчета по шаблону с визуализацией. Хранение с историей.
Перечень входных данных:
- Реестр платежей: XLS/XLSX-файл с колонками (минимум: номер договора, сумма платежа, дата платежа, ИНН контрагента, статус платежа).
- Реестр договоров: XLS/XLSX-файл с колонками (минимум: номер договора, сумма договора, дата заключения, ИНН контрагента, статус СМСП (да/нет), тип закупки).
- Критерии фильтрации: список исключений (например, статусы "аннулировано", "не СМСП"), пороговые значения (например, минимальная сумма для учета).
- Шаблон финального отчета: XLS/XLSX-файл с фиксированной структурой (разделы для процентов, распределения по критериям).
- Дополнительные метаданные: период расчета (даты начала/окончания), коды для распределения (например, регионы как строки).



Дополнительные задачи (не ключевые)



 1. Поиск всех производителей товаров с определенными характеристиками
Описание функционала:
Поиск производителей по характеристикам в интернете (открытые реестры, сайты производителей). Вывод списка с контактами, сертификатами. Таблица, экспорт.
Перечень входных данных:
- Характеристики товара: список параметров (строки: "материал: сталь", "мощность: 100 кВт").
- Источники: указанные сайты/реестры в интернете (например, реестры РФ/ЕАЭС).

 2. Поиск производителя товара / документации с указанием производителя в открытых источниках
Описание функционала:
Поиск в интернете: производитель, документация. Список с ссылками на источники.
Перечень входных данных:
- Наименование товара (строка).
- Источники: открытые сайты/реестры в интернете.

3.	Столбец C «№ позиции договора» заполняется значением, которое выявляется при сопоставлении файла «позиции» и файла «УПД». Пример: исходя из названия строки в УПД мы понимаем, что в файле «позиции» она соответствует номеру 3.
 
 
4.	Столбец D «Количество (объем)» - значение берется из соответствующего столбца УПД.
 
5.	Столбец E «Единица измерения» - значение берется из соответствующего столбца УПД.
 
6.	Столбец G «Сумма по позиции» - значение берется из соответствующего столбца УПД.
 
7.	Столбец F «Цена за единицу с НДС, руб.» - заполняется делением столбца G на столбец D.
Эталонный образец корректного заполнения расположен в папке «Лидер СМИ» и называется «Шаблон_ожидаемый итог Лидер».

Д-люкс (мойка) – с усложнением
Таблица шаблон для заполнения содержит 7 столбцов:
Номер документа	Дата подписания документа	№ позиции договора	Количество (объем)	Единица измерения	Цена за единицу с НДС, руб.	Сумма по позиции

1.	Столбец А «Номер документа» заполняется значением номера в графе «Расшифровка к акту выполненных работ №__» (!!! Номер не впечатан, заполняется от руки, распознается?)
 
2.	Столбец B «Дата подписания документа» заполняется значением наиболее поздней из двух дат подписания около печатей. (заполняется от руки, распознается?)
 

3.	Столбец C «№ позиции договора» заполняется значением, которое выявляется при сопоставлении файла «позиции» и файла «Акт». Есть несколько нюансов:
- в файле «позиции» отражены цены, отличающиеся от цен в акте. По условиям договора в акте цены на 15% меньше, чем в прайсе по договору (скидка). Также по условиям договора при «сильных загрязнениях» используется повышающий коэффициент 1,5 [(цена по прайсу – 15%) *1,5];
- в файле «акт» одна строка может содержать несколько позиций из прайс-листа;
- в прайс-листе указаны цены для 3 категорий авто (седан/ джип/ микроавтобус), поэтому при анализе первоначально нужно определить категорию авто по его модели прописанной в акте;

 Пример: исходя из марки а/м указанной в первой строке Акта мы понимаем, что нужно анализировать прайс-лист в разделе «седан». Значение «№ позиции договора» в данном случае – 82. 
 
 
Пример 2: исходя из марки а/м указанной в четвертой строке Акта мы понимаем, что нужно анализировать прайс-лист в разделе «Джип». В графе акта «наименование работы (услуги)» указано 2 услуги, соответственно будут 2 значения «№ позиции договора», в таблицу они должны быть записаны двумя разными строками. В данном случае номера позиций – 83 и 11. 
 
 
 
4.	Столбец D «Количество (объем)» - на данном этапе можно по каждой услуге ставить значение «1».

5.	Столбец E «Единица измерения» - на данном этапе можно по каждой услуге ставить значение «условная единица».
6.	Столбец F «Цена за единицу с НДС, руб.» - значение берется из файла «позиции» (прайс-лист), оно соответствует указанному номеру позиции за вычетом 15% скидки.
Пример: (скрин выше) по позиции №11 Цена за единицу с НДС, руб будет равна значению 800 – 15% = 680.
Нюанс: в случае, если используется повышающий коэффициент 1,5 (в названии позиции используются слова «сильное загрязнение»), либо если цена с учетом скидки не является круглым числом (есть «копейки»), то ячейка с таким значением должна быть окрашена в желтый цвет (для проверки/корректировки).

7.	Столбец G «Сумма по позиции» - можно перемножить значения столбца D и F и вставить получившееся значение.

Эталонный образец корректного заполнения расположен в папке «Д-люкс мойка» и называется «Шаблон_ожидаемый итог Д-люкс». Для упрощения дальнейшей работы с файлом одинаковые позиции (строки в которых совпадает столбец C и столбец F) объединяются в одну строку, их объем суммируется.
