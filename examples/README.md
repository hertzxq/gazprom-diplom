# Example files for manual testing of the «Обработка» page

Three sets, one per scenario from the technical specification.
All files are synthetic and ready to be uploaded through the UI.

## Folder layout

```
examples/
├── leader_smi/
│   ├── 01_prices_leader_smi.xlsx     # upload as «positions»
│   └── 02_upd_leader_smi.xlsx        # upload as «upd»
├── veneta/
│   ├── 01_prices_veneta.xlsx         # upload as «positions»
│   └── 02_upd_veneta.xlsx            # upload as «upd»
└── dlux/
    ├── 01_prices_dlux.xlsx           # upload as «positions»
    └── 02_act_dlux.xlsx              # upload as «act»
```

## How to test (per scenario)

1. **Upload** оба файла из папки сценария на странице «Загрузка»:
   - Файл `01_prices_*` — выбрать тип **«Позиции (прайс-лист)»**
   - Файл `02_upd_*` — выбрать тип **«УПД»**
   - Файл `02_act_*` (только для dlux) — выбрать тип **«Акт оказания услуг»**
2. Перейти на страницу **«Обработка»**.
3. В выпадающем списке «Файл позиций» — выбрать загруженный прайс.
4. В выпадающем списке «УПД / Акт» — выбрать загруженный УПД или Акт.
5. Сценарий обработки можно оставить «Автоопределение» (логика выбирается по типу файла), или явно указать «Лидер СМИ» / «Венета» / «Д-люкс» — для прозрачности.
6. Нажать **«Обработать»**. На результате появятся колонки A-G с заполненными данными, возможностью скачать XLS.

## Что лежит в каждом наборе и что должно получиться в результате

### 1. `leader_smi/` — простой УПД

**Прайс**: 7 рекламных услуг (телеканалы, радио, баннеры).
**УПД**: 4 строки — видеоролик на «Россия 1», баннер РИА Новости, радиоролик на «Маяке», видеоролик на «Первом».

**Ожидаемый результат**:
- 4 строки в таблице совпадений, все с `confidence ≥ 85` (имена в УПД близки к именам прайса).
- Колонка C («№ позиции») должна правильно сматчить: 1, 3, 4, 7.
- F = G/D (например, для строки 1: 150000/30 = 5000).
- Жёлтых подсветок не будет.

### 2. `veneta/` — простой УПД

**Прайс**: 7 картриджей разных производителей.
**УПД**: 4 строки — HP CF283A, Canon 725, Brother TN-1075, Samsung MLT-D101S.

**Ожидаемый результат**:
- 4 матча, № позиций: 1, 2, 3, 4.
- Цена F = сумма / количество.
- Жёлтых подсветок нет.

### 3. `dlux/` — сложный Акт

**Прайс**: 10 услуг, разбитых по категориям через секционные заголовки СЕДАН / ДЖИП / МИКРОАВТОБУС. Подключаются:
- скидка 15% от прайса в результирующих ценах,
- коэффициент 1.5 при «сильном загрязнении»,
- объединение одинаковых строк (одинаковые C+F).

**Акт**: 4 строки специально подобраны, чтобы каждая проверила одну фичу:

| № строки акта | Марка | Услуга | Что тестируется |
|---|---|---|---|
| 1 | Toyota Camry | «Мойка кузова» | Категория «седан», обычная скидка. F = 800 × 0.85 = **680** |
| 2 | Toyota Camry | «Мойка кузова при сильном загрязнении **и** полировка кузова» | Разбиение на 2 услуги через «и»; для мойки сработает коэффициент 1.5 → 800·0.85·1.5 = **1020** (жёлтый); полировка → 1500·0.85 = **1275** (жёлтый — копейки нет, но коэффициент тут не применится) |
| 3 | Toyota RAV4 | «Мойка кузова **и** химчистка салона» | RAV4 → джип. Мойка джип → 1200·0.85 = **1020**; химчистка джип → 3500·0.85 = **2975** |
| 4 | Mercedes Sprinter | «Мойка кузова» | Sprinter → микроавтобус. 1800·0.85 = **1530** |

Что должно появиться в результате:
- **6 строк** (4 строки акта × разбиение на услуги через «и» = 1+2+2+1 = 6).
- Жёлтая подсветка на ячейке F:
  - в строке с «сильное загрязнение» (применён коэффициент 1.5) → reason `«Применён коэффициент 1.5 для сильного загрязнения»`,
  - и/или для строк с некруглой ценой после скидки.
- Колонка D = 1 для всех, E = «условная единица» для всех.
- Колонка G = D × F.

## Дополнительные поля на форме «Обработки»

Параметры **«Номер документа», «Дата подписания», «Номер договора», «ИНН организации»** и т.д. — опциональные.

- Номер документа и дата — если оставить пустыми, бэкенд попробует достать их регексом из самого файла («Счет-фактура №», «dd.mm.yyyy»).
- Номер договора, ИНН и комментарий **сейчас в результат XLS не попадают** — они только сохраняются в метаданные задачи (см. `WORK_RESULT.md`, раздел про расхождения с ТЗ).

## Поле «Сценарий обработки»

В текущей реализации этот выпадающий список **не влияет на бэкенд**: логика выбирается по типу файла (`upd` → стандартная схема, `act` → схема Д-люкс со скидкой/коэффициентом). Полезно ставить вручную для самопроверки, но результат от него не зависит.

## Регенерация примеров

Если хочется поменять данные:

```bash
python examples/_generate_examples.py
```

Скрипт перезапишет файлы в подпапках. Зависимостей кроме `openpyxl` нет.
